# 金沢30km挑戦会

月例ランニングイベント「金沢30km挑戦会」の記録サイトです。

## 📅 開催期間
2026年4月～2027年3月（12ヶ月）

## 🎯 機能
- **会員登録・ログイン** - 名前とパスワードでシンプルに管理
- **記録管理** - 毎月のタイムと走行距離を記録
- **ダッシュボード** - 参加回数、完走数、ベストタイムを可視化
- **成長グラフ** - ペースと距離の推移をペースラベル付き棒グラフで表示
- **バッジ達成** - 7種類のバッジを集めるチャレンジ
- **シェア機能** - 成績をSNSでシェア可能

## 🏆 バッジ一覧
1. **初参加** - イベント初参加で獲得
2. **3回連続参加** - 3回連続で参加
3. **6回参加** - 合計6回以上参加
4. **完走** - 30km完走達成
5. **トリプル** - 完走3回以上
6. **ランクアップ** - ランクアップ達成
7. **エリート** - 上位ランク（4'30/km以上）で完走

## ⚡ ペースグループ
- 4'00/km（制限時間2時間00分）
- 4'15/km（制限時間2時間07分30秒）
- 4'30/km（制限時間2時間15分）
- 5'00/km（制限時間2時間30分）
- 5'30/km（制限時間2時間45分）
- 6'30/km（制限時間3時間15分）

## 🚀 使い方
1. ブラウザで開く
2. ランナー名とパスワードを入力
3. 毎月の記録を入力
4. ダッシュボードで成長を確認
5. シェアタブで成績をシェア
